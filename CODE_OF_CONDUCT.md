# Code of conduct

We want SEO Pilot to be a friendly place to work on.

- Be respectful and assume good intent.
- Keep feedback about the work, not the person.
- No harassment, insults or discrimination of any kind.
- Help newcomers find their way.

If someone breaks these rules, email **support@viral4all.com**. Maintainers may remove comments, issues or contributors that don't follow them.

This is based on the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
