# SEO Pilot fact sheet

SEO Pilot is a self-hosted SEO and AI search workspace. It runs on the owner's own server, with the owner's own provider keys.

## What it does

- Keyword research, domain overview, backlinks and rank tracking, using DataForSEO
- Site audits, with optional recurring schedules and saved evidence
- AI visibility tracking: which prompts mention a brand, and which sources get cited
- Competitor discovery with human review
- Google Search Console and Google Analytics reports
- Local SEO rank tracking
- A content studio with sources, claims, revisions, human review and export
- Reports with share links
- An MCP server, so outside AI agents can use the same tools

## Costs

The software doesn't include data or models. DataForSEO, OpenRouter and hosting are billed separately by those providers.

## What it doesn't do yet

Automatic AI article writing, publishing to a CMS, and automatic fixes on a live site are not available yet. Never say they are.

## How to connect an agent

Use the MCP address shown in Agent setup. It is this workspace's address followed by `/mcp`.

## When unsure

If you aren't sure about a product detail, say so. Point the user to Help and Support inside the app.
